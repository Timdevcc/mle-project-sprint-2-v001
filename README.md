# Предсказание стоимости недвижимости

## Описание проекта

Цель проекта — разработать и улучшить модель машинного обучения для предсказания стоимости недвижимости.

В ходе проекта проводится исследовательский анализ данных, создаются и отбираются новые признаки, выполняется подбор гиперпараметров и сравниваются различные версии модели.

Для отслеживания экспериментов, хранения артефактов и управления версиями моделей используется MLflow.

## Используемые технологии

- Python

- XGBoost

# Установка и запуск проекта

# 1. Клонирование репозитория

```bash
git clone git@github.com:Timdevcc/mle-project-sprint-2-v001.git
cd mle-project-sprint-2-v001
```

# 2. Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate
```

# 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

# 4. Настройка переменных окружения

Для работы MLflow необходимо создать файл `.env` с необходимыми параметрами подключения к PostgreSQL и S3.

Перед запуском MLflow переменные окружения необходимо экспортировать:

```bash
export $(cat .env | xargs)
```

# 5. Запуск MLflow Tracking Server

MLflow Tracking Server запускается с помощью shell-скрипта:

```bash
sh mlflow_server/run_mlflow_server.sh
```

После запуска MLflow будет доступен по адресу, указанному в конфигурации сервера.

# Этапы проекта

## Этап 1. Разворачивание MLflow и регистрация базовой модели

На первом этапе был настроен MLflow Tracking Server и MLflow Model Registry.

В качестве backend-хранилища используется PostgreSQL, а для хранения артефактов моделей — S3.

В MLflow была зарегистрирована базовая модель из предыдущего спринта. Для модели были залогированы:

- параметры;
- метрики на тестовой выборке;
- сигнатура модели;
- окружение;
- необходимые артефакты.

Скрипт для запуска MLflow находится в директории:

```text
mlflow_server/
```



## Этап 2. Исследовательский анализ данных

На втором этапе был проведён исследовательский анализ данных (EDA).

В ходе анализа:

- исследованы типы и структура данных;
- обработаны пропущенные и аномальные значения;
- исследованы распределения числовых и категориальных признаков;
- проанализировано распределение целевой переменной `price`;
- исследована зависимость стоимости недвижимости от различных характеристик;
- построены графики и визуализации.


## Этап 3. Генерация признаков и обучение модели

На третьем этапе была проведена дополнительная предобработка и генерация признаков.

Для преобразования данных использовались:

- `OneHotEncoder`;
- `RobustScaler`;
- `PolynomialFeatures`;
- `KBinsDiscretizer`;
- `ColumnTransformer`;
- `Pipeline`.

Также была протестирована автоматическая генерация признаков с помощью библиотеки `autofeat`.

На основе результатов AutoFeat были получены дополнительные признаки, описывающие взаимодействия между исходными характеристиками объектов недвижимости.

Были обучены и сравнены модели Random Forest и XGBoost.

## Этап 4. Отбор признаков

На четвёртом этапе был проведён отбор наиболее полезных признаков.

Для этого использовалась библиотека `mlxtend` и два метода Sequential Feature Selection.

Были протестированы:

- Sequential Forward Selection (SFS);
- Sequential Floating Forward Selection (SFFS).

Для уменьшения вычислительной нагрузки отбор признаков проводился на части обучающей выборки.

Для каждого метода анализировалось изменение качества модели при выборе различных наборов признаков.


На основе результатов отбора был сформирован итоговый набор наиболее значимых признаков и обучена новая версия модели.



## Этап 5. Подбор гиперпараметров и финальная модель

На заключительном этапе был выполнен подбор гиперпараметров модели XGBoost.

Для оптимизации использовалась библиотека Optuna и два алгоритма поиска:

- `TPESampler`;
- `RandomSampler`.

Оптимизировались следующие гиперпараметры:

- `n_estimators`;
- `max_depth`;
- `learning_rate`;
- `min_child_weight`;
- `subsample`;
- `colsample_bytree`.

В качестве целевой метрики использовался RMSE, который минимизировался в процессе оптимизации.

Процесс оптимизации логировался в MLflow с помощью `MLflowCallback`.


Финальная модель показала следующие результаты на тестовой выборке:


RMSE 2 440 200  
MAE 1 677 635  
R² 0.8491  
Время обучения ~45 сек  
Время предсказания ~0.84 сек  

Финальный Pipeline вместе с параметрами, метриками, сигнатурой и окружением залогирован в MLflow, а модель зарегистрирована в MLflow Model Registry.

4. финальная модель после подбора гиперпараметров.
